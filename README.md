# Project-Tutor
This plugin is inspired by devpost's "Learning-Hackthon: Spec-Driven-Development", and my experience of learning CS61A's labs before.

It gives you detailed and enlightened instructions to help you complete a project that precisely adheres to software engineering standards,offering step-to-step guidance to promote your code quality and refine your architectual thinking.

## Install
```bash
/plugin marketplace add https://github.com/yuchi423/Project-Tutor

/plugin install project-tutor@Project-Tutor
```

Then,run /reload-plugins and restart Claude Code.

Remember to create the `project` folder and include project_requirements in it.
